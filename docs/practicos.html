💻 Trabajos Prácticos

Objetivo: Implementar y configurar servicios AAA en entornos reales y virtualizados.

Cada laboratorio está diseñado para reforzar los conceptos teóricos mediante práctica hands-on.

1 Instalación y Configuración Básica de FreeRADIUS

Básico ⏱️ 60 minutos

Objetivo

Instalar FreeRADIUS y configurar autenticación básica con usuarios locales.

Requisitos

  • Máquina virtual con Ubuntu/Debian o CentOS/RHEL
  • Acceso root o sudo
  • Conexión a internet

Tareas

  1. Instalar FreeRADIUS y utilidades
  2. Configurar usuarios en el archivo users
  3. Configurar un cliente RADIUS de prueba
  4. Iniciar FreeRADIUS en modo debug
  5. Probar autenticación con radtest
  6. Revisar logs y entender el flujo

Comandos Útiles

# Instalación en Ubuntu/Debian
sudo apt update
sudo apt install freeradius freeradius-utils

# Editar usuarios
sudo nano /etc/freeradius/3.0/users

# Ejecutar en modo debug
sudo freeradius -X

# Probar autenticación (en otra terminal)
radtest testuser testpass localhost 0 testing123

Entregables

  • Capturas de pantalla del servidor en modo debug
  • Evidencia de autenticación exitosa
  • Explicación del flujo de autenticación observado

2 Integración con LDAP/Active Directory

Intermedio ⏱️ 90 minutos

Objetivo

Configurar FreeRADIUS para autenticar usuarios desde un servidor LDAP o Active Directory.

Requisitos

  • Servidor FreeRADIUS funcionando (Lab 1)
  • Servidor LDAP o Active Directory disponible
  • Credenciales de cuenta de servicio en LDAP/AD

Tareas

  1. Habilitar el módulo LDAP en FreeRADIUS
  2. Configurar conexión al servidor LDAP/AD
  3. Configurar filtros de búsqueda de usuarios
  4. Probar autenticación con usuarios del directorio
  5. Implementar atributos adicionales (grupos, permisos)

Configuración Ejemplo

# /etc/freeradius/3.0/mods-enabled/ldap
ldap {
    server = "ldap.ejemplo.com"
    port = 389
    identity = "cn=radiusadmin,dc=ejemplo,dc=com"
    password = "password_seguro"
    base_dn = "ou=usuarios,dc=ejemplo,dc=com"
    
    user {
        filter = "(uid=%{%{User-Name}})"
    }
}
Tip: Si no tienes un servidor LDAP, puedes instalar OpenLDAP localmente o usar un contenedor Docker.

Entregables

  • Configuración completa del módulo LDAP
  • Evidencia de autenticación exitosa con usuarios de LDAP
  • Análisis de atributos retornados por LDAP

3 Configuración de WiFi 802.1X

Intermedio ⏱️ 120 minutos

Objetivo

Implementar autenticación 802.1X en una red WiFi usando FreeRADIUS.

Requisitos

  • Servidor FreeRADIUS funcionando
  • Access Point con soporte 802.1X (o emulado con hostapd)
  • Cliente WiFi para pruebas
  • Certificados SSL/TLS

Tareas

  1. Configurar módulo EAP en FreeRADIUS
  2. Generar certificados SSL para el servidor
  3. Configurar AP como cliente RADIUS
  4. Configurar SSID con WPA2-Enterprise
  5. Configurar cliente WiFi para EAP-PEAP o EAP-TLS
  6. Probar conectividad y analizar logs

Configuración AP (Ejemplo)

# Configuración típica en AP
SSID: CorporativoSeguro
Seguridad: WPA2-Enterprise
Servidor RADIUS 1: 192.168.1.100
Puerto RADIUS: 1812
Secreto Compartido: mi_secreto_seguro

Configuración Cliente

# En el cliente (wpa_supplicant o GUI):
Método de autenticación: PEAP
Autenticación interna: MSCHAPv2
Usuario: testuser
Contraseña: password
Validar certificado del servidor: Sí
Importante: Asegúrate de que el certificado del servidor sea confiable en el cliente, o desactiva temporalmente la validación solo para pruebas.

Entregables

  • Configuración completa del módulo EAP
  • Configuración del AP y cliente
  • Capturas de conexión exitosa
  • Logs de FreeRADIUS mostrando el handshake 802.1X

4 Contabilidad (Accounting) y Auditoría

Básico ⏱️ 60 minutos

Objetivo

Configurar y analizar la contabilidad de sesiones en FreeRADIUS.

Requisitos

  • Servidor FreeRADIUS funcionando
  • Cliente RADIUS configurado

Tareas

  1. Habilitar accounting en FreeRADIUS
  2. Configurar almacenamiento de logs (archivos o SQL)
  3. Simular sesiones de usuario
  4. Analizar registros de accounting
  5. Generar reportes básicos de uso

Información Registrada

- Accounting-Start: Inicio de sesión
- Accounting-Stop: Fin de sesión
- Duración de la sesión
- Bytes enviados/recibidos
- Razón de terminación

Análisis de Logs

# Ver logs de accounting
tail -f /var/log/freeradius/radacct/*/detail

# Buscar sesiones de un usuario específico
grep "testuser" /var/log/freeradius/radacct/*/detail

Entregables

  • Configuración de accounting
  • Logs de sesiones completas (Start y Stop)
  • Reporte con métricas: duración promedio, datos transferidos, etc.

5 TACACS+ para Administración de Dispositivos

Avanzado ⏱️ 120 minutos

Objetivo

Implementar TACACS+ para controlar el acceso administrativo a dispositivos de red.

Requisitos

  • Servidor Linux para tac_plus
  • Router/Switch Cisco (real o emulado con GNS3/EVE-NG)
  • Conocimientos básicos de IOS/IOS-XE

Tareas

  1. Instalar tac_plus en servidor Linux
  2. Configurar usuarios con diferentes niveles de privilegio
  3. Configurar router/switch para usar TACACS+
  4. Probar acceso con diferentes usuarios
  5. Configurar autorización por comando
  6. Analizar logs de accounting de comandos

Configuración tac_plus

# /etc/tacacs+/tac_plus.conf
key = MiSecretoTACACS

user = admin {
    login = des mEYHx9k9QXUJk
    service = shell {
        priv-lvl = 15
    }
}

user = operador {
    login = des mEYHx9k9QXUJk
    service = shell {
        priv-lvl = 1
    }
}

Configuración Cisco IOS

! Habilitar AAA
aaa new-model

! Configurar servidor TACACS+
tacacs-server host 192.168.1.100 key MiSecretoTACACS

! Configurar autenticación
aaa authentication login default group tacacs+ local
aaa authorization exec default group tacacs+ local
aaa accounting exec default start-stop group tacacs+
aaa accounting commands 15 default start-stop group tacacs+
Nota: Si no tienes equipos Cisco físicos, puedes usar emuladores como GNS3 con imágenes de Cisco IOS o usar Cisco Packet Tracer.

Entregables

  • Configuración completa de tac_plus
  • Configuración del dispositivo de red
  • Evidencia de acceso con diferentes usuarios
  • Logs mostrando autorización de comandos
  • Análisis de auditoría de comandos ejecutados

6 Alta Disponibilidad y Redundancia

Avanzado ⏱️ 90 minutos

Objetivo

Implementar una arquitectura de alta disponibilidad para servicios AAA.

Requisitos

  • Dos o más servidores FreeRADIUS
  • Cliente RADIUS (NAS o AP)
  • Herramientas de sincronización (rsync o replicación de BD)

Tareas

  1. Configurar dos servidores FreeRADIUS idénticos
  2. Sincronizar configuraciones entre servidores
  3. Configurar cliente con servidor primario y secundario
  4. Probar failover (apagar primario)
  5. Probar failback (recuperar primario)
  6. Implementar monitoreo de ambos servidores

Configuración Cliente (Múltiples Servidores)

# En el NAS/AP:
Primary RADIUS Server: 192.168.1.100
Primary Port: 1812
Primary Secret: secreto1

Secondary RADIUS Server: 192.168.1.101
Secondary Port: 1812
Secondary Secret: secreto1

Timeout: 5 segundos
Retries: 3

Sincronización de Configuración

#!/bin/bash
# Script de sincronización
rsync -avz /etc/freeradius/ usuario@servidor2:/etc/freeradius/
ssh usuario@servidor2 "systemctl restart freeradius"

Entregables

  • Arquitectura de la solución (diagrama)
  • Configuración de ambos servidores
  • Script de sincronización
  • Evidencia de failover funcionando
  • Métricas de disponibilidad durante pruebas
