🔐 Servicios AAA

Autenticación, Autorización y Auditoría (AAA) es un framework fundamental en seguridad de redes que proporciona un mecanismo centralizado para controlar el acceso a recursos de red y auditar las actividades de los usuarios.

¿Por qué AAA?

En entornos empresariales modernos, es esencial tener un control centralizado sobre:

  • Quién puede acceder a la red
  • Qué recursos puede utilizar
  • Qué acciones realiza
Nota: AAA no es un protocolo en sí mismo, sino un framework conceptual que puede implementarse mediante varios protocolos como RADIUS, TACACS+, y Diameter.

Autenticación (Authentication)

La autenticación es el proceso de verificar la identidad de un usuario, dispositivo o entidad que solicita acceso a un sistema o recurso.

Factores de Autenticación

  1. Algo que sabes: Contraseñas, PIN, respuestas a preguntas secretas
  2. Algo que tienes: Tokens, tarjetas inteligentes, certificados digitales
  3. Algo que eres: Biometría (huella dactilar, reconocimiento facial, iris)
  4. Algo que haces: Patrones de comportamiento, firma
  5. Dónde estás: Geolocalización, dirección IP

Autenticación Multifactor (MFA)

La autenticación multifactor combina dos o más factores de autenticación diferentes para proporcionar una capa adicional de seguridad.

Ejemplo de flujo MFA:
1. Usuario ingresa contraseña (factor 1: algo que sabe)
2. Sistema envía código a dispositivo móvil
3. Usuario ingresa código (factor 2: algo que tiene)

Autorización (Authorization)

La autorización determina qué recursos y acciones están permitidos para un usuario autenticado.

Modelos de Control de Acceso

DAC (Discretionary Access Control)

El propietario del recurso determina quién puede acceder. Común en sistemas de archivos (permisos de UNIX).

MAC (Mandatory Access Control)

Las políticas de seguridad del sistema determinan el acceso basado en etiquetas de clasificación.

RBAC (Role-Based Access Control)

Los permisos se asignan a roles, y los usuarios se asignan a roles.

Ejemplo RBAC:
- Rol: Administrador → Permisos: Lectura, Escritura, Eliminación
- Rol: Usuario → Permisos: Lectura
- Rol: Invitado → Permisos: Lectura limitada

ABAC (Attribute-Based Access Control)

Las decisiones de acceso se basan en atributos del usuario, recurso y contexto.

Auditoría (Accounting/Audit)

La auditoría registra y monitorea las actividades de los usuarios para propósitos de seguridad, cumplimiento y facturación.

Información Capturada

  • Identidad del usuario
  • Fecha y hora de acceso
  • Recursos accedidos
  • Acciones realizadas
  • Duración de la sesión
  • Cantidad de datos transferidos
  • Resultado de las operaciones

Usos de la Auditoría

Propósito Descripción
Facturación Cobro basado en uso de recursos (ISP, servicios cloud)
Análisis de Seguridad Detección de actividades sospechosas o no autorizadas
Cumplimiento Demostrar adherencia a regulaciones (GDPR, HIPAA, SOX)
Capacidad de Planificación Análisis de uso para dimensionar recursos
Troubleshooting Diagnóstico de problemas de red y aplicaciones

RADIUS (Remote Authentication Dial-In User Service)

RADIUS es el protocolo AAA más ampliamente utilizado, especialmente en entornos ISP y redes inalámbricas.

Características Principales

  • Protocolo cliente-servidor
  • Utiliza UDP para transporte (ligero y rápido)
  • Combina autenticación y autorización en una sola fase
  • Soporta múltiples métodos de autenticación (PAP, CHAP, EAP)
  • Amplio soporte de fabricantes

Tipos de Paquetes RADIUS

Autenticación:
- Access-Request: Cliente solicita acceso
- Access-Accept: Servidor concede acceso
- Access-Reject: Servidor niega acceso
- Access-Challenge: Servidor solicita información adicional

Contabilidad:
- Accounting-Request: Cliente envía información de contabilidad
- Accounting-Response: Servidor confirma recepción

Atributos RADIUS Comunes

  • User-Name: Nombre del usuario
  • User-Password: Contraseña (cifrada con MD5)
  • NAS-IP-Address: IP del cliente RADIUS
  • Service-Type: Tipo de servicio solicitado
  • Framed-IP-Address: IP asignada al usuario
  • Session-Timeout: Duración máxima de sesión
  • Idle-Timeout: Tiempo máximo de inactividad
Limitación de Seguridad: En RADIUS estándar, solo la contraseña se cifra. El resto del payload viaja en texto claro. Para mayor seguridad, se recomienda usar IPSec o RADIUS over TLS (RadSec).

TACACS+ (Terminal Access Controller Access Control System Plus)

TACACS+ es un protocolo AAA desarrollado por Cisco, diseñado principalmente para la administración de dispositivos de red.

Ventajas sobre RADIUS

  • Cifrado completo: Todo el payload se cifra, no solo la contraseña
  • Separación de AAA: Autenticación, autorización y contabilidad son independientes
  • Control granular: Puede autorizar comandos específicos en dispositivos
  • TCP: Mayor fiabilidad que UDP

Casos de Uso Típicos

1. Control de acceso administrativo a routers/switches
2. Autorización de comandos específicos por usuario
3. Auditoría detallada de comandos ejecutados
4. Separación de privilegios según roles

Ejemplo de Autorización por Comando

# Usuario "operador" puede ejecutar:
show running-config
show ip interface brief
ping

# Pero NO puede ejecutar:
configure terminal
write memory
reload
Nota: Aunque TACACS+ es propietario de Cisco, existen implementaciones open source como tac_plus que funcionan con equipos de múltiples fabricantes.

Diameter

Diameter es el sucesor moderno de RADIUS, diseñado para superar sus limitaciones y soportar requisitos de redes móviles modernas.

Mejoras sobre RADIUS

  • Protocolo basado en TCP o SCTP (más fiable)
  • Soporte nativo para IPSec y TLS
  • Mejor manejo de errores y notificaciones
  • Soporte para roaming entre operadores
  • Extensible mediante aplicaciones
  • Soporte para peer-to-peer (no solo cliente-servidor)

Aplicaciones Diameter

  • Diameter Base Protocol: RFC 6733
  • NASREQ: Network Access Server Requirements (sucesor de RADIUS)
  • Mobile IP: Autenticación para movilidad IP
  • EAP: Extensible Authentication Protocol
  • Credit Control: Facturación en tiempo real

Uso en Redes Móviles

Diameter es fundamental en arquitecturas 4G LTE y 5G:

Interfaces Diameter en LTE:
- S6a: Entre MME y HSS (gestión de suscriptores)
- S9: Entre redes para roaming
- Gx: Control de políticas
- Gy: Facturación online

Componentes Principales

1. Servidor AAA

Centraliza las políticas de autenticación, autorización y auditoría.

  • FreeRADIUS: Implementación open source más popular
  • Cisco ISE: Solución empresarial completa
  • Microsoft NPS: Network Policy Server (integrado en Windows Server)
  • ClearPass: Solución de Aruba Networks

2. NAS (Network Access Server)

Dispositivo que solicita autenticación al servidor AAA en nombre del cliente.

  • Access Points (WiFi)
  • Switches (802.1X)
  • VPN Gateways
  • Controladores de acceso a red

3. Backend de Identidades

Almacena las credenciales y atributos de los usuarios.

  • Active Directory
  • LDAP
  • SQL Database
  • Archivos planos

Consideraciones de Seguridad

Mejores Prácticas

1. Secretos Compartidos Fuertes

# Malo:
shared secret = "secret"

# Bueno:
shared secret = "X7#mK9$pL2@qR5&nT8^wY3!vZ6*hJ4"

2. Cifrado de Comunicaciones

  • Usar RadSec (RADIUS over TLS) en lugar de RADIUS estándar
  • Implementar IPSec entre servidor AAA y NAS
  • Para TACACS+, asegurar que el cifrado esté habilitado

3. Segregación de Red

El tráfico AAA debe estar en una VLAN dedicada y protegida.

4. Redundancia y Alta Disponibilidad

  • Múltiples servidores AAA (primario y secundario)
  • Balanceo de carga
  • Replicación de configuración y datos

5. Monitoreo y Alertas

  • Monitorear intentos de autenticación fallidos
  • Alertas por patrones anómalos
  • Auditoría regular de logs

6. Políticas de Contraseñas

  • Complejidad mínima
  • Rotación periódica
  • Prevención de reutilización
  • Bloqueo tras intentos fallidos
Vulnerabilidades Comunes:
  • Secretos compartidos débiles o predeterminados
  • Comunicaciones sin cifrar
  • Falta de actualización de software
  • Configuraciones inseguras por defecto
  • Logs insuficientes para auditoría

Casos de Uso Empresariales

1. Acceso WiFi Corporativo (802.1X)

Implementación de autenticación robusta para redes inalámbricas empresariales.

Componentes:
- Access Points compatibles con 802.1X
- FreeRADIUS o Cisco ISE
- Active Directory para autenticación
- Certificados para EAP-TLS o EAP-PEAP

Beneficios:
- Autenticación por usuario (no por contraseña compartida)
- Cifrado individual por usuario
- Asignación dinámica de VLAN según grupo
- Auditoría de accesos

2. Control de Acceso a Dispositivos de Red

Autenticación y autorización de administradores para switches, routers y firewalls.

Implementación con TACACS+:
- Autenticación centralizada de administradores
- Autorización por comandos según rol
- Auditoría completa de comandos ejecutados
- Facilita cumplimiento de regulaciones

Ejemplo de política:
- Admin completo: Todos los comandos
- Operador de red: Solo comandos show y ping
- Operador de monitoreo: Solo comandos show

3. VPN de Acceso Remoto

Autenticación de usuarios remotos que acceden a la red corporativa.

Configuración:
- VPN Gateway (Cisco ASA, OpenVPN, etc.)
- RADIUS para autenticación
- MFA (segundo factor vía SMS o app)
- Asignación de permisos según grupo

Ventajas:
- Autenticación centralizada
- Soporte para MFA
- Auditoría de accesos remotos
- Desactivación centralizada de acceso

4. Network Access Control (NAC)

Control de admisión a la red basado en postura de seguridad del dispositivo.

Flujo NAC:
1. Dispositivo se conecta a la red
2. NAS solicita autenticación (802.1X)
3. Servidor AAA verifica identidad y postura
4. Si cumple políticas: Acceso completo
5. Si no cumple: Red de cuarentena
6. Remediation: Actualizaciones/parches
7. Re-evaluación y acceso completo

Validaciones típicas:
- Antivirus actualizado
- Firewall habilitado
- Sistema operativo parcheado
- Software corporativo instalado

5. Acceso a Servicios Cloud

Integración con servicios SaaS mediante federación de identidades.

Arquitectura:
RADIUS/LDAP ──▶ IdP (Identity Provider) ──▶ SaaS Apps
                (SAML, OAuth)

Beneficios:
- Single Sign-On (SSO)
- Aprovisionamiento automatizado
- Des-aprovisionamiento al terminar empleo
- Auditoría centralizada de accesos
